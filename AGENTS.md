- Old WhatsApp history is backfilled via src/lib/uazapi-history.server.ts with progress in public.history_sync_state; the backfill cron is armed on enqueue and unscheduled when the queue drains (avoids permanent polling).
- Connecting a WhatsApp number auto-imports all history: the `connection→connected` webhook (and getUazapiStatus fallback) calls startAutoHistory, which marks channels.history_discovery = pending and arms the cron. The history-backfill cron runs src/lib/uazapi-discovery.server.ts (runDiscoveryStep) first — it lists every chat/group via /chat/find + /group/list and enqueues each into history_sync_state (resumable by cursor, capped ~300/tick) — then runs the normal backfill. No manual "Sincronizar" click needed; that button (syncUazapiHistory) still works as a force-now.
